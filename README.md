# Langgan Barokah

**Langgan Barokah** merupakan aplikasi berbasis web yang dikembangkan untuk menyediakan informasi dan mengelola berbagai produk serta layanan kebutuhan masyarakat. Aplikasi ini menghadirkan beragam pilihan paket kebutuhan pokok, paket anak, layanan simpan pinjam, produk elektronik, dan layanan lainnya.

## Tentang Proyek

Langgan Barokah dikembangkan sebagai platform digital untuk memudahkan pengguna dalam memperoleh informasi mengenai berbagai produk dan layanan yang tersedia. Aplikasi ini dirancang dengan tampilan yang informatif, sederhana, dan mudah digunakan.

## Fitur Utama

- **Paket Sembako** – Menyediakan informasi berbagai paket kebutuhan pokok.
- **Paket Anak** – Menampilkan pilihan paket kebutuhan anak.
- **Paket Uang** – Menyediakan informasi layanan paket uang.
- **Simpan Pinjam** – Menampilkan informasi layanan simpan pinjam.
- **Elektronik** – Menyediakan informasi berbagai produk elektronik.
- **Layanan Lainnya** – Menampilkan informasi produk dan layanan tambahan.
